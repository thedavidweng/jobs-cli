# v1 jobs-specific error codes

Jobs adds machine-readable `error.code` values without changing the shared CLI-family exit-code categories. v1 normative codes:

- `SOURCE_UNAVAILABLE`
- `ATS_RESOLUTION_FAILED`
- `NATIVE_APPLY_UNSUPPORTED`
- `BROWSER_REQUIRED`
- `APPLICATION_INCOMPLETE`
- `ARTIFACT_STALE`
- `LINKEDIN_SESSION_REQUIRED`
- `LINKEDIN_EASY_APPLY_UNVERIFIED`

New codes may be added later; these names are stable once shipped.
